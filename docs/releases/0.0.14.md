# Arise 0.0.14

Arise 0.0.14 incorporates findings from live testing of the unified package
inspection introduced in 0.0.13 and improves Gentoo news presentation.

## Package-name inspection

`arise inspect` now accepts an exact unqualified package name:

```sh
arise inspect firefox
```

Category-qualified atoms continue to support version, slot, repository, and
USE constraints.

## Scoped diagnostics

Inspection no longer reports unresolved dependency expansions from unrelated
old VDB records while searching for reverse dependencies. Self-dependencies
are also excluded from the `Required by` result.

Repositories without `metadata/md5-cache` are reported only when they can
contain the requested package. A partial report explains when such a cache
prevents prospective candidate inspection.

## Colored, numbered news

`arise news list` now displays stable item numbers, unread markers, dates
derived from canonical news directory names when necessary, and semantic
terminal colors. The numbers can be used directly:

```sh
arise news display 3
arise news read 3
arise news read all
```

## Completion reliability

Bash completion includes `inspect`, its command-specific flags, and the
updated news operations. A contract test now requires the completion command
registry to match the CLI registry so future commands cannot be omitted
silently.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.14
arise --version
```

The final command prints `arise 0.0.14`.

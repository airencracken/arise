# Arise 0.0.40

Missing package names now suggest matching source or binary alternatives.
For example, `arise signal-desktop` suggests `net-im/signal-desktop-bin` when
that package is indexed and `signal-desktop` is absent.

- Uses the same suggestions for bare names and qualified package atoms.
- Recognizes the `-bin` alternative even when it exceeds the typo-distance
  limit, and ranks it ahead of spelling corrections.
- Omits generic index-refresh advice when a useful suggestion is available.
  Missing names without a useful suggestion retain that advice.
- Keeps suggestions deterministic and limited to three package names. Exact
  matches still resolve normally, and suggestions never substitute packages
  into a plan, including with version constraints or `--keep-going`.

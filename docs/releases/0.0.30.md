# Arise 0.0.30

Arise 0.0.30 establishes cyclomatic-complexity and performance ratchets and
ships the first performance-positive refactor produced by that audit.

## Complexity audit

The production Go baseline is now measured with `gocyclo` 0.6.0. The new
`make audit-complexity` gate prevents regressions in average complexity, the
number of functions above 50, and the existing maximum.

The audit report records the highest-risk functions and requires hot-path
complexity reductions to retain or improve wall-clock time and allocations.
An attempted resolver extraction that increased allocations was rejected.

## Phase request validation

Phase-protocol request validation is separated into command, token, path, and
package-identity checks. Its cyclomatic complexity fell from 56 to 12 while
the successful path improved from approximately 1,420 ns and three allocations
to approximately 760 ns and zero allocations.

A zero-allocation property test and benchmark protect the improvement.

## Upgrade

After syncing the overlay, reinstall the new version:

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.30
```

Verify the installed executable with `arise --version`; a successful upgrade
prints `arise 0.0.30`.

# Arise 0.0.58

Failed preflight checks now show the package, phase, and ebuild instructions at
normal verbosity. When Gentoo's build-space check fails, Arise reports the work
directory, available MiB and shortfall when measurable. It also explains how
to select a different build filesystem with `--work-dir`.

- Fetch-only honors `RESTRICT=fetch` and reports each failed package. Manual
  download errors name the destination. Checksum errors show the expected and
  received digests.
- Build failures keep the ebuild author's error messages visible alongside
  compiler output. File collisions report the conflicting paths and explain
  how to inspect ownership with `arise installed --owner PATH`.
- Merge-log write failures report the underlying filesystem error. Interruption
  checks for a checkpoint before suggesting how to resume. Recovery diagnostics
  preserve independent failures and identify already committed changes.

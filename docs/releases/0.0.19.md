# Arise 0.0.19

Arise 0.0.19 completes production binary-package publication and hardens
binary-package trust.

Built GPKGs now receive monotonic build IDs, use Portage's multi-instance
directory layout, and are published with a locked, atomic `Packages` index
containing size and cryptographic digest metadata. Concurrent builds cannot
reuse an instance ID or lose index entries.

Arise now writes genuine Portage-compatible XPAK packages and continues to
read its earlier recovery-artifact format. Indexed binhost downloads are
digest-checked and structurally validated; unverifiable binhosts without a
`Packages` index are rejected. Operators can require signed GPKG manifests
with `--binpkg-require-signature` and select an absolute gpgv keyring with
`--binpkg-trusted-keyring`.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.19
arise --version
```

The final command prints `arise 0.0.19`.

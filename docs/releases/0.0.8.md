# Arise 0.0.8

Arise 0.0.8 is a packaging and release-integrity update. Runtime package
management behavior is unchanged from 0.0.7.

## Smaller offline release inputs

Versioned Gentoo builds now use a deterministic vendor archive instead of a
complete Go module-cache archive. The release input shrinks from approximately
195 MiB to approximately 2.1 MiB while remaining fully offline.

The source repository remains unvendored. Release automation constructs the
vendor tree from the verified module graph, normalizes archive metadata, and
publishes the result through the dedicated `arise-overlay-assets` repository.

## Verifiable provenance

Each vendor archive includes a canonical manifest binding its contents to the
Arise version, exact source commit, source timestamp, Go toolchain, `go.mod`,
`go.sum`, and complete vendored module list. The overlay verifies that identity
and every content digest before compilation.

Archive generation rejects symbolic links and other unsafe vendor entries.
Manifest decoding rejects unknown fields and trailing data.

## Release gates

The normal release suite now builds the vendor artifact twice and requires
byte-identical output. It then exports a clean source tree, extracts the
artifact, verifies its provenance, and runs the entire Go test suite with:

- an empty module cache;
- an empty build cache;
- `GOPROXY=off`; and
- explicit vendor mode.

The legacy module-cache target remains available only to reproduce already
published releases. New versioned ebuilds are rendered from a separately
tested vendor-release template.

The regular benchmark targets now enforce hard deadlines, and the binary
package creation benchmark measures creation itself instead of accidentally
excluding it from the timer.

## Upgrade

After synchronizing the overlay:

```sh
emerge --ask --oneshot sys-apps/arise
```

Existing Arise installations can also synchronize and reinstall the exact
release:

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.8
```

Arise remains experimental and testing-keyworded for `~amd64`. Keep Portage
installed as the behavioral reference and recovery fallback.

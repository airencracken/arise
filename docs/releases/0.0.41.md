# Arise 0.0.41

Fixes the Firefox dependency upgrade failing during NSS preflight with
`unsupported enabled PROPERTY behavior "test_network"`.

- Accepts `PROPERTIES=test_network`, including USE-conditional declarations.
  `RESTRICT=test` continues to disable tests by default.
- Honors `ALLOW_TEST=network` for packages declaring `test_network`, and
  `ALLOW_TEST=all` for test restrictions. Tests still require `FEATURES=test`.
  Global, package.env, and command environment settings follow normal
  configuration precedence.
- Allows networking during `src_test` for `test_network` packages, matching
  Portage. Other build phases retain their configured network sandbox, and
  filesystem, PID, IPC, and mount isolation remain in place.

Verified with policy and preflight regressions, a differential comparison with
installed Portage across 24 phase configurations, and the real `nss-3.125`
ebuild's preflight using disposable build paths.

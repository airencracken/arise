# Arise 0.0.12

Arise 0.0.12 improves live package-policy explanations and terminal progress
reliability, and records the intended boundary for reusable Gentoo libraries.

## Actionable keyword diagnostics

When a newer package candidate is unavailable because of keyword policy, Arise
now reports both sides of the decision:

- the candidate's exact `KEYWORDS`; and
- the effective `ACCEPT_KEYWORDS` after global and package-specific ordered
  additions and removals.

Skipped-update warnings therefore explain why a candidate such as
`dev-python/sphinx-9.1.0-r1` is unavailable without requiring another package
tool to inspect policy state.

## Stable terminal progress

Package installation progress no longer redraws an unchanged completed frame
on every animation tick. Transient output also leaves the terminal's final
column unused, preventing automatic wrapping from turning one progress update
into repeated concatenated lines before the next package phase.

## Reusable library direction

The public-library roadmap now names
[`gentooling`](https://github.com/airencracken/gentooling) as the intended
shared Go module for reusable Gentoo system and package tooling. Arise and the
planned Maize kernel tooling are peer consumers. This release records the
dependency direction and external-consumer constraints; it does not yet
promise or extract a public API.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.12
arise --version
```

The final command prints `arise 0.0.12`.

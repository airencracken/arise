# Arise 0.0.33

This release consolidates the stabilization audit, documentation cleanup, and
follow-up checks against Portage and a disposable stage3.

- Serial and parallel execution share graph validation and transaction-commit
  checks. Invalid dependency graphs fail before execution or resume publication.
- Build-only jobs produce archives without changing installed packages, world,
  or merge timing. Their build dependencies must already be installed.
- Binary package indexes validate fields before atomic publication, preserve
  readable permissions, and order build timestamps numerically.
- Resume state rejects duplicate identities and unknown completion entries;
  canceled load waits stop even when throttling is disabled.
- Independent license validation expands nested groups such as Gentoo's default
  `@FREE` and preserves exclusions and resets. Resolver license resets clear
  earlier choices.
- The plan comparison helper uses the current update command syntax.
- The punchlist contains only actionable unfinished work. Active guides, manuals,
  links, and command examples have automated consistency checks.

Validation includes the full test suite, race detection, vet, complexity and
benchmark gates, fuzzing, mutation tests, real phase-worker integration tests,
and read-only Portage comparisons. See the
[stabilization review](../reviews/2026-09-08-stabilization.md) for evidence and
remaining limitations. Fresh-stage3 reboot validation was explicitly skipped;
this release does not claim a completed fresh-stage3 update/resume/reboot gate.

# Arise 0.0.38

This release fixes package-integrity and ownership failures found in the
September audit and makes process-replacement diagnostics relevant to the
affected process.

- Extracts GPKG images from private bytes captured during manifest verification;
  metadata and payload no longer reopen a mutable archive pathname.
- Stops merge and unmerge on missing or malformed ownership evidence. Collision
  exemptions identify exact replaced VDB entries and preserve retained slots,
  including paths with multiple installed owners.
- Omits the current Arise invocation from restart warnings. SSH instructions
  appear only when sshd is affected; ordinary applications receive ordinary
  restart or relaunch guidance.
- Uses Gentooling 0.11.1 for USE reset/removal semantics and independent
  overlapping snapshot locks.
- Updates go-git to 5.19.2 and x/crypto to 0.56.0, with their required dependency
  updates, to address the detected Git and SSH advisories.
- Propagates installed linter failures and adds regressions for the audited
  failure paths and retained-slot transactions.
- Keeps recovery objects identical when only access/change timestamps vary,
  preserving content deduplication across repeated captures.

Existing recovery and live-system constraints still apply. Configuration,
disposable-root, offline packaging, and race checks do not substitute for a
fresh-stage3 installation and a real package transaction before release
publication.

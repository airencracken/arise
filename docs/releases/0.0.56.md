# Arise 0.0.56

Broad package searches now build reverse dependencies by following the
dependency edges of returned packages. A name lookup also reuses the selected
package metadata when filling in dependency fields.

Install planning skips the reverse-dependency and package-version lookup tables
used by graph queries. JSON previews compute the approval hash once. Execution
still records per-file hashes to detect concurrent changes.

## Measured impact

| Warm workload on theshire | 0.0.55 | Release candidate |
|---|---:|---:|
| Search dev-python, 2,067 results | 1.651 s | 0.873 s |
| Preview a nano update, JSON | 1.775 s | 1.480 s |
| Preview a deep world update, text | 3.120 s | 2.937 s |
| Preview the same world update, JSON | 3.696 s | 3.347 s |

Each figure is the median from five paired runs. Both versions returned the
same search results and the same verified 83-action world plan, including its
approval hashes. The audit also covers independent comparisons with emerge.

# Arise 0.0.23

Arise 0.0.23 is the first release validated by installing a multi-package
dependency graph on a fresh Gentoo stage3 system.

The resolver now repairs a dependency omitted from a planned package before
post-solve verification completes. This fixes `app-editors/vim`, whose
`vim-core` dependency on `dev-util/xxd` participates in a versioned blocker
transition. Missing package targets also provide bounded, deterministic name
suggestions.

Fresh stage3 merges now accept Portage's empty preserved-library registry while
continuing to reject malformed non-empty JSON. News notifications consume
Portage's repository-specific relevant unread set instead of counting the
entire repository history.

Installed phase environments are now preserved as complete shell programs.
Arise restores its isolation variables after sourcing instead of deleting
assignments from the saved program, which could leave an empty conditional and
make lifecycle preflight fail with a shell syntax error.

Package-context USE calculation now applies effective profile policy after
IUSE defaults. On a hardened profile this correctly detects an installed
`dev-libs/libpcre2[jit]` changing to the profile-disabled state, bringing
`-uDN @world` back to exact Portage action-count and reinstall parity.

Successful distfile checks, downloads, and Manifest verification are concise
by default during execution. `--verbose` retains the complete artifact stream,
and package lifecycle stages now use terminal-aware semantic color without
adding ANSI sequences to automatic redirected or JSON output. Automatic color
also honors `NO_COLOR`, Portage's `NOCOLOR`, and `TERM=dumb`; an explicit
`--color=y` remains the override.

Reusable GLEP 42 news and preserved-library registry inspection now comes from
`gentooling v0.11.0`. Arise retains atomic news-state mutation, journaled merge
updates, and rollback ownership.

Resolver failures can now emit a bounded, redacted, private diagnostic with
`--save-resolver-trace`. Existing paths are never overwritten. The new
`plan-diff` command compares actions in two strictly decoded saved plans, while
`doctor package-use` performs a read-only audit for invalid or stale atoms,
stale version constraints, duplicate and contradictory rules, exact-atom
reversals, and unknown USE flags. Both inspection commands support versioned
JSON output.
The doctor also audits accept-keywords, license, env, mask and unmask policy
families plus invalid, duplicate and obsolete world selections.

`bug-report --resolver-trace` validates and redacts imported resolver evidence
again before embedding it in the private report and deterministic archive.
`--explain` renders the complete bounded candidate ledger, including why
candidates were selected, retained, rejected, or skipped and which committed
requirements applied.
Saved plans are now published atomically without replacing an existing path,
preserving prior approval and comparison evidence unless the user deliberately
chooses a new name.

This release also adds an unofficial fresh-stage3 handbook addendum using
Git-only repository synchronization and a shorter transaction-oriented
bootstrap checklist.

## Live validation

On a fresh amd64 stage3 chroot, Arise resolved, built, and committed all six
packages required for `app-editors/vim`, including `dev-util/xxd`. The
transaction completed with zero conflicts and rollback remained available
throughout execution. The corrected unread-news count matched Portage's
`news-gentoo.unread` state.

On the same hardened stage3, Arise and Portage proposed the same 65-package
`-uDN @world` plan: six new packages, one upgrade, and 58 reinstalls. Live
execution passed the previously failing `net-misc/curl` lifecycle preflight;
the complete world transaction subsequently committed successfully. Independent
post-transaction `emerge -pavuDN @world` and `arise -pavuDN @world` checks both
reported zero packages and backtrack 0/20. The longest observed action was
`sys-devel/gcc-15.3.0:15`, which committed after 8,312 seconds.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.23
arise --version
```

The final command prints `arise 0.0.23`.

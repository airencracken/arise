# Arise 0.0.23

Arise 0.0.23 is the first release validated by installing a multi-package
dependency graph on a fresh Gentoo stage3 system.

The resolver now repairs a dependency omitted from a planned package before
post-solve verification completes. This fixes `app-editors/vim`, whose
`vim-core` dependency on `dev-util/xxd` participates in a versioned blocker
transition. Missing package targets also provide bounded, deterministic name
suggestions.

Fresh stage3 merges now accept Portage's empty preserved-library registry while
continuing to reject malformed non-empty JSON. News notifications consume
Portage's repository-specific relevant unread set instead of counting the
entire repository history.

Reusable GLEP 42 news and preserved-library registry inspection now comes from
`gentooling v0.11.0`. Arise retains atomic news-state mutation, journaled merge
updates, and rollback ownership.

This release also adds an unofficial fresh-stage3 handbook addendum using
Git-only repository synchronization and a shorter transaction-oriented
bootstrap checklist.

## Live validation

On a fresh amd64 stage3 chroot, Arise resolved, built, and committed all six
packages required for `app-editors/vim`, including `dev-util/xxd`. The
transaction completed with zero conflicts and rollback remained available
throughout execution. The corrected unread-news count matched Portage's
`news-gentoo.unread` state.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.23
arise --version
```

The final command prints `arise 0.0.23`.

# Arise 0.0.11

Arise 0.0.11 makes repository synchronization faster and more predictable,
especially for unchanged repositories and installations with several configured
repositories.

## Faster synchronization

Repository synchronization now:

- checks configured repositories concurrently while preserving deterministic
  result ordering;
- avoids scanning every worktree when the remote revision is unchanged; and
- honors each repository's configured Git clone depth during fetches and
  updates.

These changes reduce unnecessary filesystem work and allow independent remote
operations to overlap.

## Clearer progress and recovery

Live synchronization progress now reports repository activity as it happens.
If an update fails, Arise preserves the useful progress context and provides
clearer recovery diagnostics instead of obscuring the repository that needs
attention.

## Native package inspection

Arise now provides native, static-binary alternatives for the package-state
capabilities commonly reached through `portageq`, `equery`, `eix`, and the `q`
tools while remaining interoperable with all of them.

The capability-oriented interface adds:

- atom-aware installed matching, presence, best-version, contents, ownership,
  USE, size, and integrity queries through `arise installed`;
- policy-aware repository, binary-package, and installed best-version queries,
  metadata lookup, ebuild paths, and virtual expansion through `arise query`;
- repository, eclass, license, configuration, protection, preserved-library,
  and native color information through `arise info`; and
- indexed maintainer and orphaned-package search.

Batch operations avoid repeated interpreter startup. On the release system,
twenty warm best-installed queries completed in 0.13 seconds with Arise versus
7.73 seconds with `portageq`; twenty best-visible queries completed in 0.70
seconds versus 6.46 seconds.

The old `arise equery` route has been removed. The man page and
`docs/tool-equivalents.md` map familiar ecosystem operations to native Arise
commands. Arise is an alternative that coexists with the established tools,
not a replacement for them.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.11
arise --version
```

The final command prints `arise 0.0.11`.

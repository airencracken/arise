# Arise 0.0.20

Arise 0.0.20 improves `arise search` color parity with `eix`.

Installed package markers now use reverse bold green, and installed versions
use the same black-on-blue presentation as `eix`. Hard-masked versions use the
red `**` marker, while package property markers such as `*l` are rendered
separately in cyan from red restriction markers.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.20
arise --version
```

The final command prints `arise 0.0.20`.

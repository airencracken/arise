# Arise 0.0.57

Package transactions keep live progress enabled by default. When a package
changes phase, Arise now clears the live row, prints the phase message, and
restores the jobs count in one terminal write. Multiline package notices stay
together when several jobs are running.

On narrow terminals, Arise fits the live row to the available columns,
accounting for color and double-width characters. The next phase starts at the
left margin, and its full package name stays in scrollback. Redirected output
continues to use plain lines.

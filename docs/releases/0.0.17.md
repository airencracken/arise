# Arise 0.0.17

Arise 0.0.17 updates package inspection to Gentooling 0.10.1.

The patch completes active evaluation of Python's kernel-check loop, including
its `MERGE_TYPE` guard, combined associative-array declaration flags, quoted
keys, and empty local `CONFIG_CHECK` reset. This supersedes 0.0.16, whose
inactive-path evaluation was correct but whose active Python `test`/`pgo` path
remained indeterminate.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.17
arise --version
```

The final command prints `arise 0.0.17`.

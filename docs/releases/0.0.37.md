# Arise 0.0.37

The independent plan audit now recognizes dependent rebuilds triggered by a
runtime slot or subslot change in the planned package state. It checks whether
the installed package's runtime dependencies become unsatisfied after the
provider update and accepts the rebuild only when the selected replacement
satisfies them. This fixes false audit failures during deep world updates,
including Perl ABI transitions.

Plan safety errors now explain the missing justification in direct terms,
confirm that package changes were not made, and report hidden and validator-
limited issues separately.

Regression coverage reproduces a `po4a` rebuild caused by a Perl subslot
change.

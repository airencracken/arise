# Arise 0.0.22

Arise 0.0.22 makes terminal activity indicators truthful.

Spinner frames no longer advance on a timer. Sync and serial package
execution advance their shared activity indicator only when a real stage or
work event is reported. Operations with measured progress continue to update
from actual item counts or transferred bytes, while an operation that emits no
new progress remains visually still.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.22
arise --version
```

The final command prints `arise 0.0.22`.

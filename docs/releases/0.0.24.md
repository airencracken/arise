# Arise 0.0.24

Arise 0.0.24 fixes source-package self-upgrades on live systems using
`FEATURES=userpriv`.

Replacement preflight inspects the installed package's saved environment to
discover old removal lifecycle hooks. That private temporary snapshot was
incorrectly sourced with the selected package's build policy, which could drop
to the `portage` user before reading the root-owned mode-0600 file. The phase
worker then exited before emitting a useful diagnostic.

Installed-environment discovery now uses the old package's `pkg_prerm`
lifecycle policy. It therefore runs with Portage-compatible removal privileges
while retaining the private snapshot and leaving ordinary build/userpriv
isolation unchanged.

The regression was reproduced while upgrading source-built
`sys-apps/arise-0.0.22` to 0.0.23 on the hardened amd64 stage3 used to qualify
0.0.23. A static 0.0.24 candidate completed that same live source upgrade.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.24
arise --version
```

The final command prints `arise 0.0.24`.

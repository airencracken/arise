# Arise 0.0.42

Stabilization release for the existing experimental `~amd64` overlay.

- Fix the Perl world-update blocker loop, repeated installed-USE work and
  verbose download-total overhead. The audited host pretend drops from over
  four minutes to about five seconds; acquisition still verifies archives.
- Tighten ABI rebuilds, retained slots, dependency domains, exclusions,
  newuse and independent final-state validation.
- Preserve resume checkpoints through planning/declined confirmation, accept
  legacy bare CPVs and retain original world favorites. Pending same-version
  rebuilds execute under `--resume --update`; dependencies no longer become
  favorites. Legacy files cannot reconstruct selections they never stored.
- Honor ask and approval for empty-update bookkeeping without erasing unrelated
  progress. Bind resume semantics and world selections into approval receipts.
- Fix source/binary replacement in disposable roots and recovery of the
  currently installed same-slot predecessor, including interruption and retry.
- Plan remote binaries from one index per host. Pretend/declined ask fetch no
  payloads; execution acquires and verifies only selected instances.
- Preserve binary subslots, select compatible build instances and explicitly
  fall back/reject required hooks instead of silently skipping them.
- Retain failed comparison diagnostics and classify failed commands inconclusive.

Full binary lifecycle execution and complete resume-option replay remain open.
Reapply original build, binary, root and job options when resuming.

Tests, race/vet, live reference comparisons, offline artifacts and source ebuild
validation cover the tested subset. The full fresh-stage3 update, interruption/
resume, linkage and reboot run is explicitly deferred for this release. Existing
fixture and planning results do not establish that acceptance gate.

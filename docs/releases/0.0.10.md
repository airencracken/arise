# Arise 0.0.10

Arise 0.0.10 turns Python transition recovery into a resumable, validated
repair loop and strengthens resolver correctness, maintenance, output, and CLI
consistency.

## Python recovery

`arise python-cleaner` can now:

- inventory obsolete Python paths, shebangs, extension modules, interpreter
  preferences, and ELF linkage;
- build and apply dependency-aware repair cohorts;
- resume interrupted package execution without repeating committed work;
- recognize packages whose installed versions have disappeared from every
  configured repository;
- jointly validate and remove only unavailable consumers independently
  classified as orphaned;
- tolerate absent linkage metadata only when filesystem inspection proves the
  package owns no ELF objects;
- reconcile a fully completed executor checkpoint with the cleaner's next
  validation stage; and
- run interpreter and module probes before publishing the new python-exec
  preference.

Every removal publishes a complete recovery set before mutation and commits
through the package journal.

## Validated conflict choices

USE conflicts now retain dependency provenance back to the direct request.
Arise presents only alternatives that survive a second resolution and the
independent final-state validator. Depending on the graph, this can include:

- enabling the required provider USE flag;
- disabling the requesting feature on the direct package; or
- deselecting and exactly uninstalling the requesting package.

Ambiguous compound conditions and unsafe removals are omitted.

## Correctness and maintenance

This release also adds or completes:

- resumable Perl transition recovery with the traditional cleaner modes;
- exact explicit-reinstall parity with emerge;
- journaled installed-package move and failed-merge maintenance;
- complete-graph slot-operator repair and independently validated final plans;
- deduplicated concurrent merge completion progress; and
- clearer Portage-style plan output with detailed timing and decision records
  kept behind debug output.

## CLI cleanup

Every top-level subcommand now has `--help`, backed by a route contract test.
`arise equery list` has been removed; use `arise installed [pattern]`.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.10
arise --version
```

The final command prints `arise 0.0.10`.

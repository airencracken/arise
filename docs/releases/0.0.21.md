# Arise 0.0.21

Arise 0.0.21 substantially improves `arise search` presentation parity with
`eix`.

Search results now collect IUSE across versions and display it on the
available-versions line, group USE_EXPAND values under their canonical names,
and apply `eix`-compatible colors and markers to version visibility,
properties, restrictions, installed versions, and installed USE state.
Installed dates, spacing, and inverse highlighting also follow `eix` more
closely.

Color selection now supports `--color=auto`, `--color=y`, and `--color=n`,
with explicit enablement correctly forcing ANSI output. The new eix search
parity document records implemented, partial, and missing query capabilities.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.21
arise --version
```

The final command prints `arise 0.0.21`.

# Arise 0.0.26

Arise 0.0.26 turns package-policy failures into concrete Gentoo configuration
instructions. Resolver diagnostics now identify the selected candidate, explain
the policy blocking it, and print commands suitable for direct review and use.

Unstable keyword failures recommend a version-pinned
`package.accept_keywords` entry for the newest candidate satisfying the user's
atom. Arise only recommends the running architecture's explicit unstable
keyword and will not suggest forcing a foreign architecture.

Dependency USE conflicts and direct `REQUIRED_USE` failures now recommend
version-pinned `package.use` entries. REQUIRED_USE suggestions use the smallest
deterministic set of flag changes that satisfies the expression. Arise
suppresses the command when profile masks or forced flags mean `package.use`
cannot resolve the conflict.

Rejected LICENSE expressions now recommend version-pinned `package.license`
entries. For alternative license groups, Arise selects one deterministic,
minimal accepted branch instead of accepting every alternative. Generated
shell values are safely quoted.

Package masks now recommend exact `package.unmask` entries when unmasking is
the complete repair. Mixed visibility is classified correctly: if a newer
version is masked while an older matching version only needs `~arch`, Arise
recommends the unmasked candidate rather than reporting that every version is
masked.

## Upgrade

The source package remains available through the Arise overlay:

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.26
arise --version
```

The release also provides a reproducible static `linux-amd64` bundle for
installing or recovering Arise without first compiling it on the target.

The final command prints `arise 0.0.26`.

# Arise 0.0.16

Arise 0.0.16 integrates Gentooling 0.10.0's bounded, phase-aware kernel
requirement evaluator into package inspection.

## Evaluated kernel requirements

`arise inspect` now reports the kernel variable state at reachable
`linux-info_pkg_setup` and `check_extra_config` invocations. It uses the
candidate's effective USE state, the requested target kernel release, and the
snapshot architecture. Inactive requirements are omitted from human output;
applicable and indeterminate requirements retain their applicability in both
human and JSON reports.

The package-inspection JSON schema is now `arise.package-inspect.v2`, and its
`kernel_requirements` value uses Gentooling's evaluated result with explicit
completeness and unresolved evidence.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.16
arise --version
```

The final command prints `arise 0.0.16`.

# Arise 0.0.59

`arise search` now shows `[U]` when a newer version in an installed slot is
visible under the host's keyword and mask settings. For example, with
`sys-apps/arise ~amd64` in `package.accept_keywords`, a newer testing release
shows up as an upgrade. A version stable only on another architecture no longer
triggers the marker on that basis.

Use `arise -pu sys-apps/arise` to see the update selected by the resolver.

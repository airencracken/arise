# Arise 0.0.18

Arise 0.0.18 updates package inspection to Gentooling 0.10.2.

Kernel requirement inspection now treats bluez's leading self-reference form
as a bounded `CONFIG_CHECK` append. It also evaluates bubblewrap's `buildonly`
merge guard and Chromium's quoted source-or-binary guard from the explicit
merge context. Arise delegates these interpretations to Gentooling; it does not
carry a separate ebuild evaluator.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.18
arise --version
```

The final command prints `arise 0.0.18`.

# Arise 0.0.9

Arise 0.0.9 corrects bare package-name validation and aligns repository-sync
colors with eix.

## Bare package targets

Commands such as `arise arise` already resolved an unqualified package name
through the resolver's exact name lookup. Independent final-state validation,
however, reparsed the original text as a strict category/package atom and
rejected the otherwise valid plan.

The audit boundary now freezes the resolver's unique canonical
category/package identity. Missing and ambiguous bare names still fail closed.
Regression coverage exercises the complete `arise` to `sys-apps/arise` route
and both adversarial cases.

## Eix-style synchronization colors

Repository change reports now use the locally installed eix conventions:

- upgrades are reverse bold cyan;
- downgrades are reverse bold blue;
- new packages are green;
- removals and regressions are red;
- changed relations are yellow; and
- category/package names remain neutral with a bold package component.

The status marker's brackets remain neutral, matching eix rather than coloring
the entire marker or package line.

## Upgrade

```sh
arise sync
arise arise
arise --version
```

The final command prints `arise 0.0.9`.

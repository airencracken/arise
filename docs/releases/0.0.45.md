# Arise 0.0.45

Fix recovery capture of installed filenames containing spaces, including
firmware files shipped by `sys-kernel/linux-firmware`.

- Parse file checksum and timestamp fields from the end of each `CONTENTS`
  record, preserving the complete filename.
- Preserve spaces in directory and symlink paths, including repeated and
  trailing spaces. Keep validation of malformed records and symlink evidence.
- Add regression tests using installed Intel and Raspberry Pi firmware records
  and verify capture and restore through both recovery and GPKG archives.

The installed firmware file list that triggered this failure contains 7,175
records; all parse successfully with this fix.

Arise remains experimental and `~amd64`. The full fresh-stage3 update,
interruption/resume, linkage and reboot acceptance run remains deferred.
The final live-system installation remains a separate manual canary.

See the [compatibility matrix](../compatibility/PORTAGE_COMPATIBILITY_MATRIX.md)
and [remaining work](../../PUNCHLIST.md).

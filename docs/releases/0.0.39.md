# Arise 0.0.39

Fixes upgrades that stop before installation with `malformed sym entry` while
capturing an installed package for recovery. The recovery parser now accepts
the checksummed symlink records written by Arise, as well as Portage records
without a checksum.

- Reads the timestamp after the optional MD5 field and preserves the exact
  symlink target for recovery archives and installed-package GPKGs.
- Writes new symlink records in Portage's target-and-timestamp format, including
  ownership records for preserved libraries. Portage no longer interprets an
  extra checksum as part of the target.
- Rejects malformed checksums and timestamps. Capture still rejects symlinks
  whose target or filesystem type differs from the installed record.
- Adds regressions using the Go and gofmt records that triggered the failure,
  including capture and restore through both archive formats.

If an older Arise cannot upgrade itself because of this failure, run the
upgrade with the 0.0.39 static binary or a binary built from this release.

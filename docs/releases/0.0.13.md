# Arise 0.0.13

Arise 0.0.13 introduces unified package inspection and expands its use of the
Gentooling library for consistent, reusable Gentoo package-state analysis.

## Unified package inspection

`arise inspect` explains installed and prospective package state from one
stabilized snapshot:

- installed and available versions;
- effective visibility with keyword and mask evidence;
- effective USE decisions, including forced and masked flags;
- dependency atoms and installed reverse dependencies;
- static and indeterminate kernel configuration requirements;
- installed out-of-tree module artifacts and target-kernel rebuild state; and
- typed diagnostics when VDB or repository evidence is incomplete.

The default stabilized-lockless mode supports unprivileged inspection.
`--locked` additionally observes Portage state locks, while `--strict` rejects
partial package evidence.

```sh
arise inspect sys-kernel/genkernel
arise inspect --target-kernel="$(uname -r)" sys-fs/zfs-kmod
```

## Structured interoperability

`arise inspect --json` emits the versioned
`arise.package-inspect.v1` contract using consistent snake-case fields. The
schema is shipped in `docs/schemas/package-inspect-v1.schema.json` for Maize,
future TUIs, and other package-tooling integrations.

## Gentooling integration

Arise now consumes Gentooling 0.9.0 for repository discovery and candidates,
effective configuration and profile policy, package atom matching, consistent
system snapshots, visibility and USE evaluation, kernel requirements, and
installed out-of-tree module classification. `@module-rebuild` uses root-aware
VDB evidence rather than relying on a scan of the running host's
`/lib/modules`.

## Upgrade

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.13
arise --version
```

The final command prints `arise 0.0.13`.

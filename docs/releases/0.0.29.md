# Arise 0.0.29

Arise 0.0.29 accelerates dependency resolution and restores the installed
package identity in upgrade output.

## Resolver performance

Package policy matching now caches parsed configuration atoms and candidate
CPVs. This avoids repeatedly parsing the same values while evaluating USE,
mask, keyword, and profile policy across candidate and complete-graph scans.

On the reported `@world` workload, dependency resolution fell from 24.228
seconds to 4.001 seconds without changing the 57-action plan.

## Upgrade display

Verified plans now retain the installed version, slot, subslot, repository,
and USE context for each replacement. Pretend output consequently shows the
package being replaced, matching Portage's bracketed previous-identity form:

```text
[ebuild     U  ] app-shells/bash-completion-2.18.0:0::gentoo [2.17.0:0::gentoo]
```

## Upgrade

After syncing the overlay, reinstall the new version:

```sh
arise sync
arise -1 --reinstall =sys-apps/arise-0.0.29
```

Verify the installed executable with `arise --version`; a successful upgrade
prints `arise 0.0.29`.
